### about

I'm Youssouf — an ML engineer who likes turning research into things that actually run in production. My happy place is the messy middle: feature pipelines that don't drift, agents that don't hallucinate (much), and models that survive contact with real users.

Currently most interested in **LLM-powered agents**, **RAG systems**, and the **MLOps** layer that keeps all of it upright.
